# References

Real places, rooms and things to learn from, such as dance studios, clubs, stages and lighting rigs. Each one needs a
note on what to take from it.

- Add a link and a line: what it is, and what we learn from it ("mirror wall height", "how the DJ booth faces the
  room").
- Add a picture only if we have the right to share it. Otherwise, a link is enough.
- Never another world's assets or screenshots used as parts. Another world may be named as inspiration, and only
  that.
- Club art and photos go here only when the person who made them says yes, credited by the name they choose.
