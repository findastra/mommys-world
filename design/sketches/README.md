# Sketches

Astra's own drawings of Mommy's World, saved as originals.

- Name each one `<space>-<what>-<date>.<ext>`, for example `rave-house-stage-20261020.png`.
- Never overwrite a sketch. An edited or traced version is a new file, and its ledger row names the original.
- A sketch an AI touched (cleaned up, coloured or traced) is labelled `ai-assisted` and keeps its original next to it.
