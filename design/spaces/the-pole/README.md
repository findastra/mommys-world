# The pole and its staircase

One pole runs through every floor of the September draft, from Hell up to Space (decision 10). It is made new for
this world. Nothing is copied from Astra's Infinite Pole.

## Decided (decision 11)

- **Staircase:** a see-through staircase spirals around the pole. Astra's old brief names Daydream Castle as a
  picture reference only, so no part of it is copied.
- **Showcases:** they happen around the pole, so every floor can watch.
