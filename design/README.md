# Design

This is where Mommy's World gets thought through, before anything is built.

People's originals come first: Astra's sketches, the club's wishes and photos of real places. AI helps sort these
and write them up. It doesn't make the designs.

- [`spaces/`](spaces/): one folder per space, each with a `README.md` brief.
- [`sketches/`](sketches/): Astra's own drawings.
- [`references/`](references/): real places, rooms and things to learn from, and what to take from each.
